# AyuGram iOS: сборка и установка

AyuGram здесь — это официальный Telegram для iOS (исходники Telegram-iOS) с добавленными функциями AyuGram:
режим призрака, сохранение удалённых сообщений, история правок, фильтры, ID в профилях, скрытие рекламы и историй,
подтверждение отправки стикеров. Всё остальное, включая дизайн, звонки, истории, стикеры и голосовые, — как в оригинале.

## Как устроена сборка

Windows не умеет собирать iOS-приложения, поэтому сборка идёт на macOS-раннере GitHub Actions (образ `xcode-27`,
Xcode 27.1). Полная сборка Telegram занимает несколько часов. Если одно задание не укладывается в лимит GitHub
(6 часов), workflow сохраняет кэш и сам запускает следующее задание, которое продолжает с того же места.

IPA собирается без подписи Apple, с тестовой подписью из `build-system/fake-codesigning`. SideStore переподписывает
его вашим Apple ID при установке.

## 1. Ключи Telegram API (один раз)

1. Откройте <https://my.telegram.org>, войдите по номеру и выберите **API development tools**.
2. Скопируйте **App api_id** и **App api_hash**.
3. Сохраните их как секреты репозитория (значения вводятся в окне PowerShell и уходят прямо в GitHub):

```powershell
gh secret set TELEGRAM_API_ID --repo dedsec-reth0/ayugram
gh secret set TELEGRAM_API_HASH --repo dedsec-reth0/ayugram
```

## 2. Сборка

```powershell
cd D:\Desktop\PYProject\ayugram-telegram
.\ayugram\scripts\build.ps1
```

Скрипт запустит сборку и дождётся релиза, затем скачает `.\out\AyuGram.ipa`. Готовый IPA также появляется в разделе
**Releases** репозитория.

## 3. Установка через SideStore

1. Установите SideStore по инструкции <https://sidestore.io>.
2. Перенесите `AyuGram.ipa` на iPhone и откройте SideStore → **My Apps** → **+** → выберите файл.
3. Бесплатный Apple ID подписывает на 7 дней: раз в неделю нажимайте **Refresh All**.
4. У бесплатного Apple ID ограничено число App ID (10 за 7 дней), а в Telegram 6 расширений. Если не хватает,
   включите в SideStore **Remove App Extensions** (пропадут виджет, «Поделиться» и расширения уведомлений).

**Push-уведомления.** Серверы Telegram отправляют push только приложениям, чей APNs-сертификат им известен; у
переподписанной сборки такого нет, поэтому уведомления при закрытом приложении не приходят. Это ограничение всех
неофициальных сборок, установленных через SideStore.

## 4. Где настройки AyuGram

**Настройки → AyuGram.** Историю правок сообщения открывает долгое нажатие на отредактированное сообщение →
**История правок**.
