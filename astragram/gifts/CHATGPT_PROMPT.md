# Промпт для ChatGPT: подарки AstraGram

Вставьте промпт ниже в ChatGPT (модель с генерацией картинок) и замените `[ПОДАРОК]` на то, что нужно,
например «плюшевый мишка с бантом». Сделайте всё в одном чате, по одному подарку за раз: так стиль у всех
подарков выйдет одинаковым.

Готовое положите в папку `astragram/gifts/source/<id>/` (id — из JSON, который выдаст ChatGPT), и скажите мне.

---

```
Ты — художник подарков для мессенджера AstraGram. Нарисуй ОРИГИНАЛЬНЫЙ подарок: [ПОДАРОК].
Не копируй и не повторяй подарки, стикеры или эмодзи Telegram, Apple или других компаний — придумай свой дизайн.

СТИЛЬ (одинаковый для всех подарков):
- Мягкий глянцевый 3D, как у дорогих эмодзи: округлые формы, объём, плавные градиенты, лёгкий блеск.
- Свет сверху слева, мягкий; без резких теней и без тени на «пол» (тень рисует приложение).
- Насыщенные, но не кислотные цвета; чистые края, без шума и текстур-зерна.
- Предмет целиком в кадре, по центру, занимает ~80% холста, вид спереди или 3/4.
- Без текста, букв, цифр, логотипов, рамок и фона.

ФОРМАТ КАРТИНОК:
- PNG 1024×1024, ПРОЗРАЧНЫЙ фон.
  Если прозрачный фон не получается — сплошной чистый зелёный #00FF00 (без градиента и бликов на фоне).
- Сначала дай ЦЕЛЫЙ подарок: файл `full.png`.
- Затем тот же подарок, РАЗРЕЗАННЫЙ НА ЧАСТИ для анимации: каждая часть — отдельный PNG 1024×1024
  на прозрачном фоне, СТРОГО на своём месте (если сложить все слои друг на друга, получится ровно `full.png`).
  Части, которые будут двигаться, — отдельно: например тело, голова, левая лапа, правая лапа, бант, глаза
  (открытые) и глаза (закрытые, для моргания). Под подвижной частью дорисуй то, что открывается при движении,
  чтобы не было дыр. 3–7 частей, не больше.
- Названия файлов: `full.png`, `part_<название>.png` латиницей (part_body.png, part_head.png, part_arm_left.png…).

ОПИСАНИЕ ДЛЯ ПРОГРАММИСТА — в конце ответа дай блок JSON ровно в таком виде:
{
  "id": "латиница-через-дефис, например teddy-bow",
  "title_ru": "название по-русски",
  "title_en": "name in English",
  "rarity": "common | rare | epic | legendary",
  "price_sparks": число (common 15–50, rare 75–150, epic 200–500, legendary 750+),
  "layers": [
    {"file": "part_body.png", "z": 0},
    {"file": "part_head.png", "z": 1, "pivot": [0.50, 0.62]},
    ...
  ],
  "animation": [
    {"layer": "part_head.png", "type": "tilt", "degrees": 6, "seconds": 2.4},
    {"layer": "part_arm_right.png", "type": "wave", "degrees": 25, "seconds": 1.2},
    {"layer": "part_eyes_open.png", "type": "blink", "closed": "part_eyes_closed.png", "every_seconds": 3.5},
    {"layer": "*", "type": "bob", "pixels": 12, "seconds": 2.0},
    {"type": "sparkles", "color": "#FFD36B", "count": 6}
  ]
}
- "z" — порядок слоёв: 0 самый нижний.
- "pivot" — точка, вокруг которой часть вращается, в долях холста от левого верхнего угла (0..1),
  например плечо для лапы, шея для головы.
- Типы анимаций: bob (покачивание вверх-вниз), tilt (наклон туда-обратно), wave (помахать),
  blink (моргнуть), spin (поворот целиком), pulse (лёгкое «дыхание»), shine (блик пробегает),
  sparkles (искорки вокруг). Подбери 2–4, которые подходят этому подарку, всё зацикленное и спокойное.
```

## Что пришлось бы сделать, если хочется «как в Telegram» один в один

Подарки Telegram — векторная Lottie-анимация (TGS), её делают аниматоры в After Effects + Bodymovin. ChatGPT такое
не нарисует. Если когда-нибудь закажете аниматору — пусть отдаёт `.json` (Lottie) или `.tgs` 512×512, 60 к/с,
до 3 секунд, зациклено: такие файлы я вставлю в приложение без переделок.
