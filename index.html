Мы взяли Telegram и убрали всё, что мешает. Ты решаешь, отправлять ли «в сети» и «прочитано». Удалённое остаётся у тебя. Лишнее исчезает. А весь код — на виду.

01 / 06

Режим
призрака

Читай, слушай и смотри истории, не отправляя «в сети», «прочитано» и «печатает». Включается одной кнопкой с призраком над списком чатов.

  • Без отметок о просмотре историй, голосовых и кружков
  • Прочитать — только когда ответишь сам
  • Сервер Telegram о подключении знает: режим не всесилен
02 / 06

Удалённое
остаётся

Сообщения, которые собеседник удалил, остаются в чате с меткой. У каждого сообщения — история правок.

  • Работает и в каналах
  • Одноразовые фото и видео не сгорают
  • Журнал удалённого по всем чатам
03 / 06

Чаты
под Face ID

Выбранные чаты открываются только по лицу. Их текст скрыт уже в списке чатов, а в переключателе приложений — заставка.

  • Face ID для настроек AstraGram
  • Запрет сторонних клавиатур
  • Буфер обмена очищается через минуту
04 / 06

Огоньки
с друзьями

Переписывайся каждый день — огонёк растёт: Искорка, Огонёк, Пламя, Костёр, Звезда. Счёт виден на всех твоих устройствах.

  • Серийчик с гардеробом одёжек
  • Восстановление пропущенного дня
  • Значок AstraGram у друзей
05 / 06

AI
со своим ключом

Перевод, пересказ чата, ответ, расшифровка голосовых и текст с фото — через любой OpenAI-совместимый API.

  • Текст уходит в сервис только по твоему действию
  • Без ключа — бесплатный сервис с лимитом
  • Плагины на JavaScript
06 / 06

Монохром
и стекло

Оформление только в чёрном, белом и серых. Материал стекла на выбор: стандартный, прозрачный, матовый.

  • Пружинящий отклик кнопок
  • Музыка капсулой в профиле
  • Без историй и рекламы в каналах

DEDSEC

DEDSEC

Тишина всех групп и каналов одной кнопкой, включая новые. Исключения — в профиле чата.

// плагин: команда .flip AstraGram.onSend(msg => { if (msg.text.startsWith(".flip")) msg.text = msg.text .slice(5).split("") .reverse().join("") })

Плагины на JavaScript

Свои команды и обработчики сообщений. Перед установкой приложение предупреждает: плагин видит ваши сообщения.

Без рекламы

В каналах нет рекламных постов и похожих каналов.

Уведомления без push

Сообщения приходят, пока AstraGram держит соединение в фоне.

/скидк[аи]/спам#рекламакрипт.*

Фильтры

Скрывать сообщения по словам и регулярным выражениям.

🔖 Закладки📝 Шаблоны🔔 Уведомления по словам🆔 ID в профиле⏱ Секунды во времени📤 Экспорт настроек

Мелочи, которые решают

Закладки, шаблоны ответов, детали сообщения, режим стримера, скриншоты и копирование без запретов.

Код открыт. Весь.
Исходники лежат на GitHub под лицензией GPL-2.0. Основа — открытый код Telegram-iOS.

    
Собирает GitHub, не мы
Каждая сборка идёт на GitHub Actions — её журнал видно всем. Релиз помечен тегом на коммит, из которого собран.

    
Ключи API — твои
При первом запуске ты вводишь свои API ID и Hash с my.telegram.org.
